# Reduced motion toggle

`<ReducedMotionToggle>` renders an HTML checkbox inside a `<label>`, which lets the user turn reduced motion on or off. This component uses the `useUserPrefs` hook to maintain & toggle the reduced motion state. More on that here: https://wethegit.github.io/react-hooks/use-user-prefs

## Install

```bash
npx @wethegit/components-cli add reduced-motion-toggle
```

## Usage example

The component must render inside the [UserPreferencesProvider](https://wethegit.github.io/react-hooks/user-preferences-provider), which holds and saves the preference. Without the provider, clicking the toggle will throw an error.

```jsx
import { UserPreferencesProvider } from "@wethegit/react-hooks"

import { ReducedMotionToggle } from "@local/components/reduced-motion-toggle/reduced-motion-toggle"

function YourComponent() {
  return (
    <UserPreferencesProvider>
      <ReducedMotionToggle />
    </UserPreferencesProvider>
  )
}
```

The label defaults to "Reduced motion". Pass `children` to change it.

```jsx
<ReducedMotionToggle>Turn off animations</ReducedMotionToggle>
```

`className` is applied to the `<label>`. All other props are passed to the `<input>`.
